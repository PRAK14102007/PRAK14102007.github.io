# Prakhar Pandey — Visual Design Portfolio

A responsive, scroll-animated portfolio featuring graphic design, cultural posters, event identity and illustration work.

## Publish with GitHub Pages

1. Upload the contents of this folder (not the enclosing folder itself) to the root of `PRAK14102007.github.io`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to finish deploying, then open `https://PRAK14102007.github.io`.

## Add more work

The **＋ Add work** form stores extra projects in the current browser using localStorage. These additions do not automatically sync to other devices or appear for other visitors. The ten original portfolio projects are included in `script.js`. For public updates, replace `projects.json`/the matching `defaultProjects` entries in `script.js` and upload new images under `assets/`.
